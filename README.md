# Harivignesh Ganesan - Portfolio

A professional portfolio website built with React, Tailwind CSS, and Framer Motion.

## 🚀 Tech Stack

- **Frontend Framework**: React 18
- **Styling**: Tailwind CSS (Dark/Light mode enabled)
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Navigation**: React Scroll
